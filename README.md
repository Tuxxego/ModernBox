# ModernBox
A very cool mod for WorldBox.

> [!IMPORTANT]
> **ModernBox has existed for over 3 years and has become one of the largest mods ever created for WorldBox.**
>
> As WorldBox has continued to evolve, keeping ModernBox updated has become increasingly difficult. I have mostly moved on to developing InfiniteBox, which you can learn about at https://tuxxego.com/infinitebox.
> As such, I will let you guys improve and overhaul the mod.

## `M1` - Original ModernBox

**Compatibility:** ⚠️ Pre-2025 WorldBox only

The variant of ModernBox that 70% of players remember

* Approximately **95% of the code was written by Tuxxego**.
* The remaining work was contributed by **Dank** and **BlueNight** during the **10.0 update**, which is what this branch is based on.
* Previous versions are not here, this is the oldest you'll find, sorry I don't want 500 branches.

> [!WARNING]
> This branch does **not** run on modern WorldBox versions.

> [!NOTE]
> It would be incredibly cool to see someone successfully port this branch to modern WorldBox.

---

## `M2`

**Compatibility:** ⚠️ Pre-2025 WorldBox only

The latest known version of ModernBox 2.

This branch was created after additional developers were granted access to the project and represents a major overhaul of the original mod.

Features include:

* Large content expansion (new vehicles, invasions, etc)
* Space system from SpaceBox implemented
* Contributions from multiple developers
* Probably the most expansive version of ModernBox ever created

> [!WARNING]
> This branch only works on pre-2025 WorldBox versions.

> [!NOTE]
> Porting M2 to modern WorldBox would be an enormous undertaking, but would be a huge benefit for the ingsoc party. Whoever does this will get a very cool role in Tuxia.

---

## `M3`

**Compatibility:** ✅ Modern WorldBox
**ArmyBox Compatibility:** ❓ Unknown

The skeleton and foundation of M3 were created almost entirely by **MORFOS**.

M3 was a complete remake of ModernBox and became the **first version designed to work with the new WorldBox version**.

> [!NOTE]
> I cannot currently confirm whether this branch functions correctly on ArmyBox.

## `M5`

**Compatibility:** ✅ Modern WorldBox

M5 is the biggest update ModernBox has received since **ModernBox 2.0 in 2023**.

Major additions include:

* Space content fully restored
* Massive bug fixing effort
* Hyperfuture Era
* Many new menus
* Sex system

> [!WARNING]
> Along with many fixes came many new bugs.

---

## `M5TrainsNStuff`

**Compatibility:** ✅ Modern WorldBox

The latest evolution of M5, heavily overhauled by **Dww** and **MORFOS**.

New content includes:

* Trains
* Kaiju
* Oceans

> [!WARNING]
> Some users have reported issues with this branch, which is why it is maintained separately from standard M5.

# Downloads

Going forward, separate release ZIPs will be provided on GameBanana for branches that work on modern WorldBox.

Currently planned releases include:

* `M5`
* `M5TrainsNStuff`
* Possibly `M3`

If insane people successfully port `M1` or `M2` to modern WorldBox, those branches will receive official release ZIPs as well.
