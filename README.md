# ModernBox-5
A Mod for Worldbox

Welcome to the Modern and Space Age.

## WorldBox 0.51.2 contribution

This branch targets build 719 and adds research-based civilization development, corrected resource/weapon paths, and replacement sprites for missing effects. Use **Automatic research** in the ModernBox Eras tab to enable the full development path; **Research and development** shows each kingdom's next requirements.

See [the contribution notes](docs/worldbox-0.51.2-contribution.md) for behavior, save handling, thresholds, validation, limitations and sprite provenance. This is a community contribution for maintainer review.
